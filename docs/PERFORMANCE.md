# 本地受控性能基线

测量日期：2026-10-21（Asia/Shanghai）。**这是当日源码指纹在本机上的历史合成基线，不是当前完整应用性能验收，也没有竞品优势结论。**

2026-10-22 已修改身份匹配和网络 owner 复核，当前源码指纹与此报告不同；本轮没有重测性能。尤其下列已知地址结果未包含新增的成功端口定向 `lsof` 复核，不能外推为最新系统发现速度。保留原数字供后续在相同口径下对照，不用正确性测试耗时替代性能测量。

## 环境与复跑

- Apple M4 Pro、arm64、12 个逻辑核、48 GiB 内存；系统内核报告 Darwin 27.0.0。
- 已有官方 Node 24.22.0；Playwright 1.64.1，复用现有匹配的浏览器，不复制到随机路径。
- 测量时没有并行运行本轮浏览器测试；机器仍非独占，未固定电源状态、清理磁盘缓存或保证冷启动。
- 资料库、5 个 HTTP 网页和全部子进程由工具创建，结束完整清理。每页只有随机 UUID 路径返回 HTML，根路径实测 404，避免普通端口扫描将测试网页收录到日用资料库。

```sh
# 使用当前 Node（至少 22.13）
npm run benchmark:local

# 本次正式轮使用已缓存的目标内置版本
.build-cache/node-v24.22.0-darwin-arm64/bin/node tools/benchmark-local.js
```

完整原始样本与条件记录在 `test-results/performance-baseline.json`。本次 `status=completed`、退出码 0、`cleanup.completed=true`；该目录忽略提交，后续运行会覆盖报告。

## 不代表什么

- 已知地址探测**不是完整系统发现耗时**。它不包含候选端口根路径分支、lsof 枚举、PID / cwd / Git 身份读取、失败端口或大量历史地址。
- 截图页面只有静态 HTML 和内联 CSS，无 JavaScript、图片、远程字体 / API 或登录态；不代表复杂开发应用的耗时。
- CPU / RSS **只属于源码 Node 核心**。不含菜单栏、网页前端、驱动进程、测试服务或 Chromium；没有测出「整个应用只用这些资源」。
- 启动不含 macOS 菜单栏壳、Finder、系统信任评估、首次解包 / 下载浏览器成本。
- 本轮没有设达标阈值，不把小样本快值当成稳定保证，也不据此称为轻量或比竞品快。现有旧应用包的本机磁盘占用约 340 MiB，与本次源码核心内存是不同指标。
- 五项目浏览器流程验证正确性，不测真人找回时间、误选率或一周留存。
