## 资料迁移与回到旧源码

- 本地资料格式升为 **v3**，与软件包版本不同。旧 `UUID.png` 不改名，v2 迁移前以 `library.v2.backup.json` 保留原元数据，不覆盖既有副本，v1 同理；迁移不复制或暗中保留已删图片。
- `before-restore.json` 是原子写入的仅元数据检查点，不含旧图或图片版本引用。恢复是替换库，恢复图片需要独立勾选，默认关闭。
- 旧 Alpha.1 源码**不可**直接写 v3 目录，会拒绝新格式；仅覆盖迁移 JSON 不能找回已明确删除 / 替换的图片。
- 要回旧代码，先用新源码导出，再恢复到**独立的空资料目录**。导出仍为容器版本 1、内含兼容 **v2** 状态，图片明确勾选才含；备份自己保管，不让旧 App 使用升级后目录。
- 清理失败按站内提示检查权限 / 存储后重试，完成前不分享资料目录。细节见 [资料故障边界](DATA_INTEGRITY.md) 和 [快速使用](QUICK_START.zh-CN.md)。
