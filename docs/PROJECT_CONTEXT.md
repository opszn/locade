## 实现事实

- React / Vite 前端、Node 原生 HTTP 环回 API、JSON 本地存储、Playwright 按需截图；原品牌文件未改，默认资料 `~/.locade`。
- 本地 HTTP(S) 发现、搜索 / 收藏 / 重命名 / 最近访问、离线卡片、手动地址；首次进入和前台无编辑时周期发现。
- Project / Endpoint 身份模型；端口 → 监听 owner / 启动时间 → cwd → 应用目录，只读 Git HEAD；monorepo / worktree / 同目录多服务保守区分。
- 手动目录绑定 / 解除、缺失路径提示、显式 Finder / VS Code / Cursor 白名单打开。只验证 IDE 打开意图，不在测试中拉起用户 IDE。
- 端口复用阻断、保留原封面；过时窗口和菜单栏源码都走 `/open/:id` 最新门控。核对前后仍有瞬时竞争，匿名无 owner 不算强身份。
- 同名核对展示目录 / 地址 / 封面 / 短 ID，默认无选择；批量忽略整批验证凭据、事务更新，可撤销 / 恢复，不按标题合并；重开清空勾选，优先当前搜索组。
- 全局 / 项目截图许可、删除、容量、本地 gzip 备份和恢复；图片恢复独立勾选默认关闭，坏输入不先删除图片，v1 迁移保留元数据副本。
- 所有业务确认 / 校验 / 进度 / 错误为自有 UI，10 类确认、默认取消、Escape、焦点循环 / 返回；打开失败有品牌返回页，API 保持 JSON。
- 单实例、原子资料写入、生命周期所有权；不执行项目脚本或停止外部项目，不上传截图或增加遥测。
