# 快速使用

[English](QUICK_START.md) | 简体中文

更新：2026-10-24。已发布源码版本是 **v0.3.0-alpha.1**，Alpha.2 仍是**未发布开发变更**，不是可下载的 App。本指南区分两者，避免按错误版本寻找功能。

## 1. 安装已发布源码

当前推荐 macOS Apple Silicon，Node.js **22.13+**；推荐 Node 24，另有 Node 26 回归。其他系统与 Intel Mac 尚未验收。发现通过 `lsof` 获得进程线索，不可用时只探测常用端口。Locade 不替你安装 Node 或启动项目。

在新目录获取固定的 Alpha.1 源码：

```sh
git clone --branch v0.3.0-alpha.1 --depth 1 https://github.com/opszn/locade.git
cd locade
```

选择**一种** npm 依赖来源；同一锁文件和完整性校验，不改全局 npm 配置：

```sh
# 默认：公共 npm 官方源
npm ci

# 可选：公共第三方 npmmirror 镜像
npm ci --registry=https://registry.npmmirror.com
```

使用同一 `node_modules` 的服务运行期间不要执行 `npm ci`。不自动切源或降低 TLS 安全。npm 镜像**不改变浏览器下载来源**。

```sh
npm run build
npm start
```

打开终端打印的环回地址，通常为 `http://127.0.0.1:4400`。保留该终端；在这个终端 Ctrl+C 只停止 Locade 服务，不停止外部项目。端口占用时不要结束未知进程；可选择独立资料库和端口：

```sh
PORT=4401 LOCADE_DATA_DIR="$PWD/.locade" npm start
```

同一资料目录只允许一个实例。默认资料在 `~/.locade/`，不一定在源码目录。不要通过代理或隧道对外暴露管理服务。

## 2. 发现、自愿截图、打开

先用熟悉的终端或 IDE 自行启动网页项目，Locade 不运行其脚本、不停止它。进入项目库会触发发现，也可手动重新发现；前台无编辑时通常每 20 秒刷新，可在设置关闭自动发现。在线状态是最近探测，不是实时保证。

Alpha.1 使用中文文案；未发布的 Alpha.2 开发分支新增下表英文对应项。固定 Alpha.1 源码没有语言选择或新指南。

| 动作 | Alpha.1 中文 | Alpha.2 英文 |
| ---- | ------------ | ------------ |
| 添加最终的本地 HTML 地址 | 添加项目 | Add project |
| 再次探测 | 重新发现 | Rediscover |
| 管理许可 | 隐私与截图 | **Privacy & screenshots** |
| 开启截图许可 | 允许本机截图 | **Allow local screenshots** |
| 单卡截图 | 生成截图 | **Capture screenshot** |
| 打开复核后的项目 | 打开项目 | **Open project** |
| 比较同名项，不合并 | 同名待核对 | **Review same names** |

没有 Chromium 仍可发现、收藏、打开。截图默认关闭，安装 Chromium **不等于授权，也不会批量截图**。需要封面时，在 Locade 源码目录手动执行：

```sh
npm exec --no -- playwright install chromium
```

先确认页面没有秘密，再到设置明确允许截图，逐卡触发；也可对单项目保持禁止。截图不复用日常浏览器登录态，只允许环回资源，所以登录、远程 CDN / API 或 WebSocket 页面可能不完整。不要为了体验截图而使用敏感或不可信页面。

使用卡片的打开项目动作，而不是历史裸地址。已知复用地址会被阻止，应重新发现原项目，不要绕过保护。同名不代表同一项目，按目录、地址、进程线索与封面对比；不会自动合并。离线卡片仍然保留，Locade 不替你重启。

## 3. Alpha.2 开发增量有什么不同

以下功能需要对应开发提交，不是包版本写着 Alpha.1 就具备。尝试前读 [未发布说明](ALPHA2_RELEASE_NOTES.md) 和分支 / 提交；本指南不要求将日用资料库切到未合入分支。

- **Quick start** 对应「使用指南」，可重新打开已收起的引导。语言可跟随支持的浏览器语言，或保存在本机显式选择；项目名称、路径、Git 分支不翻译。
- 浏览器就绪只检查可执行文件，不证明系统策略允许启动；重试不会安装或执行浏览器。缺少浏览器不影响发现、收藏、打开。
- 清理警告表示旧图或部分图片可能仍留磁盘。「重试图片清理」（**Retry image cleanup**）只重试清理；完成前不要说隐私删除已成功或分享资料目录。资料提交失败保留原图；提交成功后的清理仍可能失败。原始文件系统错误可能保持原文。
- 本地资料格式为 **v3**，图片有独立版本。升级前保留原 v1 / v2 元数据副本，旧封面不改名；旧代码不能直接读写 v3 库。迁移 JSON 副本不是图片备份。
- 要回到旧代码，先用新源码导出备份，再恢复到**独立的空资料目录**。导出仍含兼容的 **v2** 状态，图片须自愿勾选，备份自己保管。不要用旧 JSON 覆盖运行中的库，或让旧 App 直接使用升级后的目录。

## 4. 常见问题与安全下一步

| 情况 | 下一步 |
| ---- | ------ |
| 没发现项目 | 确认已自行启动且返回成功 HTML；手动添加含路径的最终本地地址。跳转、纯 JSON、自签名 HTTPS、需鉴权页面可能遗漏。 |
| 浏览器缺失或下载失败 | 先用发现 / 收藏 / 打开。Chromium 与 npm 分开下载，见 [安装来源](INSTALLATION.md)，不要禁用 TLS 或系统安全。 |
| 找到浏览器文件，截图仍失败 | 文件就绪不是启动验收。查看站内错误、页面与可信网络设置，或直接打开项目；不要换路径、重签或重复启动受阻原生来规避策略。 |
| 误开、错误封面或疑似丢资料 | 暂停破坏性动作，不靠删除 / 合并真实卡片或覆盖恢复来消除症状。用匿名步骤和短小的脱敏错误码反馈。 |
| 本机服务不可用 | 检查自己启动的终端。Alpha.2 有站内重连，Alpha.1 可待服务就绪后刷新；不要结束未知进程。 |

## 5. 自己保管资料

资料和截图留本机，没有遥测或截图上传，但可能包含路径、地址与秘密。忽略卡片只隐藏，不删除图片；截图没有默认过期。禁止截图会请求删除；Alpha.2 若清理失败会持续提醒并允许重试。导出 / 系统备份不随应用内删除消失。

导出 / 恢复在隐私设置中。恢复是**替换**而非追加；恢复图片需要独立勾选，默认关闭。`before-restore.json` 只有元数据，没有旧图，不能靠它撤销封面丢失。停止服务并移除源码不会删除 `~/.locade/` 或导出备份。

普通问题或首次困惑见 [安全反馈指南](FEEDBACK.md)。漏洞或私人资料暴露使用 [GitHub 私密安全报告](https://github.com/opszn/locade/security/advisories/new)，不要公开 issue，不贴真实路径、截图、资料库、备份、凭据或会话令牌。

写好指南不等于陌生使用者安装通过、一周试用或原生验收；没有正式 App / DMG 下载和 npm 发行。另见 [已发布 Alpha.1 说明](RELEASE_NOTES.md) 与 [Alpha.2 计划](ALPHA2_PLAN.md)。
