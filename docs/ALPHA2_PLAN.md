# Alpha.2 计划与待办

更新：2026-10-24。用户已同意开始下一轮开发。目标版本暂定 `v0.3.0-alpha.2`，**此处是计划，不是完成证明或发布日期承诺**。已发布 Alpha.1 tag 保留，不移动，不将未完成功能包装成新 Release。

## 目标与边界

让没有参与开发的人可以独立安装、看懂界面、完成「发现 → 明确允许截图 → 生成封面 → 打开正确项目」。优先改善首次体验、双语覆盖和错误恢复，不继续堆功能。

本轮只做源码 Web。沿用暖纸 / 炭黑 / 橙红品牌、环回管理接口、本机资料和显式截图许可。不增加项目启停、任意 shell、云同步、隧道、AI、自动遥测或自动下载执行安装器；不重建 / 覆盖已放行的原生文件，不为绕过策略反复换路径。

## 发布门槛

误开项目、身份错配、错误封面继承或资料丢失属于阻断问题；先复现并修复，不通过清理用户卡片来消除症状。双语覆盖、自动测试与真实安装试用是不同证据。技术候选可先交付；若真人验证未完成，发布说明必须明确，不宣称所有验收通过。

原生菜单栏实际交互、稳定安装身份、登录项、干净机器、跨版本升级 / 卸载、签名公证安排在下一阶段；不要求用户先提供签名凭据才允许继续源码开发。
